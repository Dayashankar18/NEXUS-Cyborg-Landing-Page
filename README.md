# NEXUS — Beyond Human

A responsive cyborg / cyberpunk technology landing page built with vanilla HTML, CSS and JavaScript.

## Features
- Responsive desktop, tablet and mobile layouts
- Custom inline SVG cyborg illustration (no external image assets)
- Neon cyan / dark metallic visual system, grid overlays, scanlines and animated radar
- Mobile navigation toggle
- Smooth anchor navigation and reduced-motion support
- Technology feature cards, protocol section and contact CTA

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Customize
- Edit copy and sections in `index.html`.
- Change colors and breakpoints in `style.css`.
- Update navigation behavior in `script.js`.

The contact CTA currently uses a placeholder `hello@nexus.example` address. Replace it with your real contact address before publishing.
